
# Student Skill & Internship Tracker

## Project Description
The Student Skill & Internship Tracker is a full-stack web application that helps students manage their skills, explore internship opportunities, and track their internship applications.

## Objectives
- Add and manage student skills.
- Add internship opportunities.
- Apply for internships.
- Track internship applications.
- Store project data in a MySQL database.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- REST API
- Git and GitHub

## Main Features
1. Dashboard with summary counts.
2. Skill management.
3. Internship management.
4. Internship application tracking.
5. MySQL database integration.

## Project Structure
- frontend: HTML, CSS and JavaScript files.
- backend: Node.js and Express.js server.
- MySQL: Stores skills, internships and applications.

## How to Run
1. Install Node.js and MySQL.
2. Create the `student_tracker` database and required tables.
3. Configure database credentials in `backend/.env`.
4. Install backend dependencies using `npm install`.
5. Start the backend using `node server.js`.
6. Open `frontend/index.html` using Live Server.

## Conclusion
This project demonstrates frontend development, backend API creation, database connectivity and CRUD-related operations in a full-stack web application.
